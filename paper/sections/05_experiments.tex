\section{Experiments}
\label{sec:experiments}

\subsection{Experimental Setup}

We validate our theory using SIREN networks~\citep{sitzmann2020siren} with $\code{hidden\_dim}=64$, $\code{num\_layers}=4$, and $\code{w0}=30.0$.
All experiments use the Set5 dataset~\citep{set5} with image size $48\times48$.
The network is trained to fit transformed images (scale or rotation) with Adam optimizer and cosine annealing.

For each transformation group, we conduct two experimental conditions:
\begin{itemize}
    \item \textbf{MAML meta-training}: Meta-learned initialization across the transformation family
    \item \textbf{Independent training}: Separate training for each transformation parameter
\end{itemize}

\subsection{Orbit Regularity Analysis}

We measure orbit regularity via two complementary metrics:
\begin{itemize}
    \item \textbf{PC1}: First principal component variance explained (higher $\Rightarrow$ more regular orbit)
    \item \textbf{Closeness $C$} for rotation orbits: Return distance after $360^\circ$ / expected distance under uniform coverage
\end{itemize}

\subsection{Extrapolation Validation (S3/R3)}
\label{sec:extrapolation}

To test the generalization of our tangent predictions, we conduct extrapolation experiments:
\begin{itemize}
    \item \textbf{S3}: Scale extrapolation to $s \in \{0.2, 2.0\}$ (outside training range $[0.5, 1.5]$)
    \item \textbf{R3}: Rotation extrapolation to $\phi = 390^\circ$ (outside training range $[15^\circ, 165^\circ]$)
\end{itemize}
