# Para_space Whiteboard Research Plan

This file is now a one-page route map. The operational entry for ARIS is
`doc/aris_project_brief.md`.

## Goal

Restart the project as a clean study of INR / arbitrary-scale SR fitting and
adaptation dynamics. The first useful question is not "how do we continue the
old story", but "what small observable object can survive strong controls?"

## Starting Scope

- Use scratch SIREN and scratch LIIF only.
- Use existing data, trajectory schema, alignment helpers, metrics, and training
  entrypoints.
- Treat image content, local smoothness, edges, texture, scale, response, update,
  and feature behavior as candidate explanations.

## Default Route

1. Ask ARIS to propose one small node from `doc/aris_project_brief.md`.
2. Freeze the node question, metric, controls, stop rule, commands, and artifact
   paths.
3. Run only the smallest experiment needed to decide whether the route deserves
   another node.
4. Stop for user review before expanding data, model scope, or claim strength.

## Current Non-Claims

The project currently has no positive mechanism claim. Old detailed route
history has been reduced to `doc/history_negative_summary.md` and should be read
only as a warning list.
