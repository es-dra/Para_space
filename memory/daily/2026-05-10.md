关键确认：

- `LIIFModel.gen_feat(inp)` 只执行 `self.encoder(inp)`，返回 unfold 前 feature map，形状为 `[B, 32, LR_H, LR_W]`。`feat_unfold=True` 的 3x3 unfold 发生在 `query_rgb()` 内部，不在 `gen_feat()` 内部。
- 当前四个 C-minimal 候选 run 均为 reduced LIIF：`hr=48`、`lr=12`、`sr=4`、`full_snapshots=(11, 138531)`、`model_config_name=LIIF_CONFIG_REDUCED`。
- C-minimal 每个 cell 的 trajectory object 应为 `[T, 32]`，但 cell 不能当作独立 iid 样本，因为 EDSR encoder convolution 和图像空间自相关会让相邻 cell feature 相关。
- 实现时必须注意：`LIIFModel.forward()` 会先把输入从 `[0,1]` 归一化到 `[-1,1]` 再调用 `gen_feat()`。若 C-minimal 直接调用 `gen_feat()`，必须显式执行 `inp = (lr_tensor.unsqueeze(0) - 0.5) / 0.5`。
- 发现一个旧风险：`analyze_stage_b_liif_unit_audit.py` 当前直接 `model.gen_feat(lr_tensor.unsqueeze(0))`，没有显式归一化；这可能影响已生成的 LIIF internal-unit screen 数值。该发现不推翻“decoder_input 继承 encoder_feature”的结构判断，但后续若正式使用 internal-unit 数值，应先修正并重跑。

冻结的 C-minimal 主设计：

- 主 target：per-cell `orthogonal_energy_fraction`，使用已有 `update_decomposition_metrics()` 语义。
- 辅助 target：`straightness`、`effective_rank`。
- 诊断 target：`path_length`、`endpoint_norm`、`mean_step_norm`，不作为主 gate。
- 主要 geometry 增量应在 `coordinate + content` 之后计算，不只是在 content 之后计算。
- 回归应报告 blocked spatial CV R² 与 in-sample R²；主 gate 用 blocked CV，避免 12x12 cell 空间自相关导致过乐观。
- content features：LR 3x3 support 的 mean、variance、gradient magnitude。
- geometry structure features：structure tensor anisotropy/coherence 和 orientation 的 circular encoding，例如 `anisotropy`、`anisotropy*cos(2theta)`、`anisotropy*sin(2theta)`。
- `LR/HR discrepancy` 不应叫 pure geometry；应作为 target difficulty / residual feature 单独报告。若它解释力强，结论应是“高频残差需求预测 feature trajectory complexity”，不是“几何机制成立”。

初步 gate：

- 最小 diagnostic runs：`LIIF_reduced_baby_sr4_seed123`、`LIIF_reduced_woman_sr4_seed42`、`LIIF_reduced_bird_sr4_seed42`、`LIIF_reduced_head_sr4_seed42`。
- Go signal：baby/woman 的 strict geometry increment `ΔR²_cv = R²_cv(coord+content+geometry) - R²_cv(coord+content)` 至少达到约 `0.03`，四个 run 的 median 至少约 `0.02`，且 bird/head 不出现强负增量（例如 `< -0.01`）。
- Hard stop：若 3/4 runs 中 geometry strict increment `<= 0.01`，或 `coord+content` 已解释 `coord+content+geometry` 的 90% 以上且没有任何 run 达到约 `0.03`，停止该路线，不继续修 descriptor。
- 论文级 claim 不能只靠四个 run；若 diagnostic 有信号，应扩展到当前全部 7 个 reduced LIIF runs，并优先检查 baby 多 seed 稳定性。

- blocked CV 在 12x12 grid 上仍可能不稳定；结果只能作为 diagnostic gate。
- target difficulty / LR-HR discrepancy 可能比 structure geometry 更强，届时应接受“content/difficulty driven”解释。
