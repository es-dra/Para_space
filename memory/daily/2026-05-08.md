## Entry 2 - Scientific Review And Next-Step Plan

完成范围：

- 对当前 Stage A/B/C 进展进行审稿式复核，没有启动新实验或修改分析代码。
- 重新区分三类证据：
  - 平台证据：Stage B 可靠，支撑继续做只读 Stage C 方法审计；
  - 正向线索：baby 多 seed、woman seed42、高内容强度 patch、feature trajectory 在 context descriptor 下增强；
  - 反向约束：bird output 仍 failure，head output 仍 weak/tiny，coord-Jacobian 多数仍 tiny，context descriptor 增加 top2 close frac。
- 明确下一步不应做 full Stage C、等变性比较、pretrained LIIF/LIIF-EQ 或训练加速 claim。

证据支持的判断：

- 当前主假设还没有被稳定证明。更准确的说法是：当前 probe 在部分图像、部分内容区域和部分 response object 上能测到局部 correspondence，但无法捕捉跨图像统一规律。
- bird/head failure 不是单一 confound 可解释。拟合质量、response norm 异常、strict near-tie 非唯一近邻都不能单独解释；上下文不足是合理方法问题，但 `rgb_grad_context` 也没有修复 output response。
- feature trajectory 可能是更容易被局部 geometry/context 预测的 response object；output trajectory 更接近最终任务，但也更容易暴露 failure。
- `rgb_grad_context` 的副作用很重要：它改善 feature response，同时增加 descriptor 空间拥挤和 top2 near-tie，多义匹配风险更高。

建议下一步方案：

1. **首选：结构化 matching 诊断，而不是新模型或新数据**
   - 在现有 patch descriptor 外加入显式上下文门控或二阶段 matching：
     - local `rgb_grad` 先选 top-k；
     - context similarity、边缘方向一致性或低频上下文相似性再筛选；
     - 记录 top-1 是否改善 response percentile。
   - 成功标准不是“平均 effect 变大”本身，而是：
     - bird/head output `worst_response_frac` 下降；
     - baby/woman 不明显变差；
     - top2 close / ambiguity 不进一步恶化；
     - 改善能被 patch-level 例子解释。

2. **并行但次优先：多候选 response oracle diagnostic**
   - 对每个 anchor 的 geometry top-k candidate，报告 top-k 中 response 最近者与 geometry top-1 的差距。
   - 目的：判断 failure 是“候选集合里有好匹配但排序错了”，还是“geometry top-k 集合本身没有 response 近邻”。
   - 如果 oracle top-k 明显好于 top-1，说明 matching/reranking 值得做；如果 oracle 也差，说明 descriptor 或 response object 更根本不匹配。

3. **暂缓：更多 seed、更多图、等变性**
   - 当前瓶颈是 probe/matching 是否测对对象，不是样本量。
   - 继续扩展可能只会把方法不充分包装成更多混合结果。

工作流优化审查：

- 当前最容易犯的错误是把 context descriptor 对 feature response 的改善当作主假设证据。应明确它只是方法审计线索。
- 下一步应保留只读、可复现、同一输出目录外的 diagnostic 产物，不写临时 launcher。
- 所有新指标都应与已有 rgb_grad baseline 同表报告，避免选择性呈现。

证据支持的结论：

- Probe / patch extraction / raw full snapshot response reconstruction 不是当前主要故障点。synthetic response 与 fitted exact-repeat periodic 都能产生正向 known-duplicate signal。
- Nonrepeat negative control 三个 seed 均未误报，说明 gate 没有简单地把任意图像都判为正。
- Controlled fitted exact-repeat 不能证明 geometry 机制：三个 periodic seed 的 content-intensity-only control 都接近 geometry，且 seed123 的 response percentile / Spearman 不稳定。
- 自然图 bird/head failure 不应再归因于“response 重建代码坏了”；更可能是当前 H1 操作化方式不足，即 `local patch appearance/geometry nearest neighbor -> raw output trajectory similarity` 没有对齐 LIIF response 的实际决定因素。
- 当前正例更可靠的解释是 image-internal repeated content / local appearance signal，而不是已剥离 content/coordinate confound 的跨图像 geometry-response law。

未解决风险与下一步：

- p 值仍应作为置换诊断，不是独立样本显著性检验；known-group directed pairs 之间高度相关。
- Controlled periodic 是 exact-repeat 场景，过于容易让 content-only control 成功；下一步若继续挽救核心目标，必须做 geometry-vs-content / coordinate 解耦 gate。
- 若转向 model-internal unit，应预注册 LIIF decoder input / encoder feature trajectory / query-conditioned support 的 response object 与 controls，不能继续自然图 descriptor 搜索。
- 不应启动等变性、pretrained LIIF/LIIF-EQ、update prediction 或训练加速 claim。
- 若不做更重的 response/unit 重定义，Stage C 应降级为 failure-audit / negative diagnostic 贡献。

## 专家评审

可靠：本轮完成了受控 synthetic smoke、fitted exact-repeat positive、nonperiodic negative control、多 seed 复核、HR geometry source 复核、输出 schema 检查和相关测试。结论不是依赖单个 seed；三 seed negative control 稳定不误报，三 seed periodic 都有 known-duplicate 正信号。

不足：controlled gate 没有证明 geometry 独立机制，反而暴露 content confound；periodic seed123 未过严格 fitted support，说明 response trajectory 仍有 seed/优化路径不稳定。受控图是人工 exact-repeat，不代表自然图。

下一步是否合理：继续自然图扩样或等变性比较不合理；合理节点是 geometry-vs-content / coordinate 解耦 gate，或更重的 model-internal response/unit 重定义。若不愿进入该成本，应诚实降级 Stage C。

防止过度宣称：不能说研究方向已经失败；也不能说 controlled positive 证明了主假设。当前最强表述只能是：平台与 response probe 可工作，但当前 patch matching / raw output trajectory 操作化不足，尚未捕捉到跨图像稳定、能击败 content/coordinate controls 的 geometry-response 规律。
