C-minimal all failed to provide a clean positive mechanism gate, what is the
current mainline of the project?

Supervision:

- Real subagent: one read-only supervision/review subagent checked whether the
  project should continue mechanism search, switch to controlled setting, or
  contract to probing / failure-audit.
- Strongest objection: the project still lacks a stable response/update object
  that answers the original scientific question across images.

## Decision

Return to the mainline by contracting the near-term project to:

> fitting-dynamics probing + failure-audit, with controlled mechanism testing
> as the only admissible mechanism-recovery branch.

This is not a positive mechanism result. It is a route correction after several
mixed or negative gates.

## Rejected Alternatives

- Continue natural-image Stage C descriptor / rerank / response-object repair.
- Expand C-minimal to all reduced LIIF runs based only on baby/woman small
  positive increments.
- Start pretrained LIIF / LIIF-EQ, equivariance comparison, update prediction,
  or training acceleration.
- Revive PCA/PC1 as a parameter-space mechanism story.

## Consequences

- The project should not default to another natural-image geometry experiment.
- A paper-facing path should emphasize what was measured, what failed, and what
  negative gates teach about fitting-dynamics probes.
- If the mechanism route is pursued, the next node must be a controlled
  mechanism test with pre-registered positive/negative controls and a Metric
  Validity Gate.

## Conditions To Reopen Mechanism Claims

Mechanism claims require a controlled setting or a newly justified object that:

- distinguishes content, coordinate, orientation/anisotropy, and residual
  difficulty;
- passes positive and negative controls;
- reports failure cases;
- prevents natural-image descriptor search from re-entering as the main
  evidence generator.
