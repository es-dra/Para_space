# Negative History Summary

This file is the only historical warning note that ARIS should read by default.
It is not a result index and should not be used as positive evidence.

Earlier explorations around R0/R1, Stage B-prime, Stage C, parameter descriptors,
response trajectories, local geometry matching, and update concentration did not
produce a clean inheritable positive claim. The useful lesson is mostly what to
control for:

- step norm and learning-rate schedule can create smooth-looking trajectories;
- layer scale and endpoint drift can dominate parameter-space measures;
- time-permuted updates, random-walk controls, and matched-step random
  directions are necessary baselines for trajectory descriptors;
- local patch or content matching can look meaningful unless spatial, residual,
  and null-content controls are strong;
- pretrained checkpoints, LIIF-EQ assets, equivariance comparisons, and training
  acceleration claims are inactive and should not be reopened by default.

Current work should start from `doc/aris_project_brief.md` and build new
evidence from scratch.
